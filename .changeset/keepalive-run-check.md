`doctor` tells a keepalive that runs from one that only exists. When `gh` is signed in (or `GITHUB_TOKEN` is set) and the project is a GitHub repository, it reads the runs of "Supabase keepalive": a green run in the last four days reads `✓ The keepalive ran green 27 h ago (<url>)`; none reads `!` with how the latest run ended and the first annotation of its job (`"The job was not started because recent account payments have failed…"`), or that the workflow never ran, with the `gh workflow run` command to trigger it. Without `gh` the file check stays as it was.

To update a project: nothing.
