The site can serve the files of Media itself instead of Supabase Storage, for the Free plan's egress: `defineCmsConfig({ media: { delivery: 'build' } })` (`'storage'` by default, nothing changes for existing projects). `linkchar-cms media:pull` runs in `amplify.yml` before `next build` and copies the files of the published content (images, posters, videos, PDFs and the images inside rich text) into `public/cms-media/<path>` with the publishable key: a file already there with the same path and size is kept, files no longer published are removed, a file Storage refuses is reported and the build goes on, and the command fails only when Supabase can't be read; it ends with what it downloaded, reused and removed and the weight of it all. Outside Draft Mode the readers resolve `src` to `/cms-media/<path>` when the file is on disk and to the Storage URL otherwise; the preview always reads Storage. `withCms` adds `Cache-Control: public, max-age=31536000, immutable` for `/cms-media/:path*` to `headers()`. `doctor` fails with `'build'` while `amplify.yml` lacks `linkchar-cms media:pull` before the build or `public/cms-media/**/*` under `cache.paths`, or `.gitignore` lacks `public/cms-media/`, and warns when the published files weigh more than `media.budgetMb` (1024 by default). `init --media-delivery build` writes the config key, an `amplify.yml` with the lines and the `.gitignore` entry. The video details read "El sitio sirve el video desde su propio CDN: Supabase lo entrega una sola vez, al publicar." with `'build'`, and the Free plan's egress is quoted as 5 GB. New exports: `localMediaUrl`, `LOCAL_MEDIA_FOLDER`, `MediaDeliveryType` in `@linkcharsoft/cms/core`, `MEDIA_HEADERS` in `@linkcharsoft/cms/next`; `mediaItemFrom` takes a `urlOf` and `createSiteReaders` a `hasLocalMedia`.

To update a project: nothing with `'storage'`. To serve the files from the site, set `media: { delivery: 'build' }` in `cms.config.ts`, end `preBuild` in `amplify.yml` with `pnpm exec linkchar-cms media:pull` (after `build:report --start`), add `public/cms-media/**/*` under `cache.paths` and `public/cms-media/` to `.gitignore`; `doctor` checks the three.
